# 2026年8月产业平台、硬件路线与信息核验

> 作者：Damon Li
> 更新日期：2026年8月22日

## 核验原则

| 证据等级 | 可接受来源 | 写入方式 |
| :--- | :--- | :--- |
| A | 论文原文、开源仓库、数据/模型托管页、正式官方文档 | 可作为技术机制、复现与下载依据。 |
| B | 公司官网、官方研究博客、招聘页、官方赛事页 | 明确标注为“官方披露”。 |
