## 证据等级

| 等级 | 定义 | 写入方式 |
| :--- | :--- | :--- |
| A | 论文原文、官方代码/模型/数据页、同行评审正刊或正式数据 DOI | 可以写方法、公式、实验和资源；须给出链接与边界 |
| B | 公司官方研究页、官方演示、官方会议日程 | 可写明确披露的产品/研究事实；不可补推未披露架构或数字 |
| C | 公众号、媒体、个人纪要、转载 | 仅登记为发现线索；需要继续回溯后才可转换为 A/B 级结论 |
