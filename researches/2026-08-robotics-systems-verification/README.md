# 机器人系统控制与可复现性核验专题

> 作者：Damon Li
> 更新日期：2026年8月23日

本专题归档从公众号线索回溯到同行评审论文、官方运行环境和数据 DOI 的机器人系统研究。它补充课程中的 VLA/抓取路线：对于医疗、足式和穿戴系统，完整的具身研究还必须说明物理约束、传感闭环、人机/临床风险、实验统计与可复现资源。

## 文档导航

- [Science Robotics 系统案例：磁控介入、ANYmal、外骨骼与软体穿戴机器人](./science-robotics-systems-control-and-reproducibility.md)

## 归档原则

| 内容 | 纳入条件 | 当前处理 |
| :--- | :--- | :--- |
| 方法、公式、实验数字 | 同行评审论文或可访问原文支持 | 使用引用链接，并标明 trial、参与者或仿真 rollout 的统计单位 |
| 代码和数据 | 官方 GitHub、Code Ocean、Zenodo、Dryad 等可访问记录 | 链接到下载入口，并单独说明硬件/人体试验不可自动复现 |
| 产业或媒体说法 | 只有公司发布/转述，缺少原始材料 | 仅登记到证据台账，不据此生成性能结论 |
