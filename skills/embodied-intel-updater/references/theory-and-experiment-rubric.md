# 理论推导与实验设计核验标准

在 `embodied-intel-updater` 识别到候选论文或官方技术报告后读取本文件。目标不是复述摘要，而是补足作者省略的假设、目标函数、推导中间步骤、实验协议与证据边界。

## 1. 理论补全流程

1. **定位原始定义。** 从方法、附录、supplementary、代码和引用工作中抽取符号表：观测 $o_t$、状态 $s_t$、动作 $a_t$、语言 $\ell$、策略 $\pi_\theta$、模型 $p_\phi$、奖励 $r$、数据集 $\mathcal D$。
2. **写清学习问题。** 指出模型在优化什么条件分布、假设哪些变量可观测、训练/部署时哪些信息不可用。
3. **重建目标函数。** 由概率分解、最大似然、ELBO、Bellman 方程、policy gradient、flow matching 或扩散 SDE/ODE 推到论文实际损失。每一项说明其数据来源、梯度路径和作用。
4. **拆解算法步骤。** 给出训练期输入/输出、推理期输入/输出、动作块执行与闭环刷新频率；必要时写伪代码。
5. **补写隐含假设。** 包含同步标定、动作空间统一、相机固定、接触可忽略、世界模型短视界准确、离线数据覆盖充分、仿真动力学可信等。
6. **区分“论文已证明”和“合理解释”。** 解释性推导必须明确为“基于公开目标函数的推导”，不得假称作者原文结论。

## 2. 按方法类别的最小推导清单

| 类别 | 必须补全的数学对象 | 必须审查的失败模式 |
| :--- | :--- | :--- |
| Behavior Cloning / VLA | $\pi_\theta(a_t\mid o_{\le t},\ell,e)$、动作归一化、NLL/MSE、chunk horizon | covariate shift、动作延迟、跨本体对齐、训练—推理分布偏移。 |
| Diffusion / Flow Matching Policy | 噪声路径、条件变量、velocity/score 目标、采样步数、guidance | 多步采样延迟、动作块误差累积、约束不可满足。 |
| World / Action Model | $p_\phi(s_{t+1}\mid s_t,a_t)$ 或视频/latent 条件动态、rollout 损失、规划目标 | 长视界漂移、OOR/OOD、模型漏洞、视觉质量与控制质量脱钩。 |
| Model-based RL / MPC | value/reward/dynamics、Bellman backup 或短视界优化 | 模型偏差、探索风险、约束违反、真实数据校准。 |
| Imitation / IRL | 占用度量、专家分布、判别器/奖励恢复 | 专家覆盖、奖励不可辨识、对抗训练不稳定。 |
| Sim-to-Real | 参数随机变量 $\xi$、训练分布 $p(\xi)$、系统辨识目标 | 未建模接触、传感器时延、视觉域差、硬件磨损。 |
| 多智能体 / 人形全身控制 | 联合状态、通信、动作耦合、IK/WBC 约束 | 碰撞、平衡、异步观测、个体数量变化。 |

## 3. 实验设计审计表

对每篇核心材料填充下表；缺失项必须明确写“论文未披露”。

| 维度 | 必查问题 |
| :--- | :--- |
| 任务 | 任务数量、成功定义、初始状态随机化、语言/视觉条件、长时程程度是什么？ |
| 数据 | 来源、小时数/轨迹数、模态、训练验证测试切分、是否存在场景/对象/操作者泄漏？ |
| 本体 | 机器人型号、DoF、传感器、执行器、控制频率、动作表示和坐标系是什么？ |
| 对比 | 基线是否使用相同数据、相同预算、相同硬件、相同动作空间和相同安全过滤？ |
| 统计 | trials 数、随机种子、均值/方差/置信区间、显著性检验、失败案例是否提供？ |
| 消融 | 数据规模、架构模块、损失项、动作块长度、推理步数/延迟、prompt/后训练是否单独消融？ |
| 真实部署 | 真机次数、实时频率、干预次数、恢复机制、碰撞或安全事故、Sim-to-Real 协议是什么？ |
| 复现 | 代码、权重、数据、许可证、环境版本、训练成本、硬件是否公开？ |

## 4. 实验可比性规则

- 只有任务、数据、动作空间和评价协议一致时，才能把成功率直接并列比较。
- 真机成功率与仿真成功率必须分表呈现；视频演示不属于统计评测。
- 公司博客的结果使用“官方披露”；预印本使用“论文报告”；正式会议/期刊使用“同行评审论文”。
- 对缺少 trial 数或方差的指标，写“点估计，统计不确定性未披露”。
- 对无法访问训练数据/权重的工作，列出复现障碍，而不是推测超参数。


字数不够时，不要填充行业背景；优先补齐符号、推导、实验协议、消融和失败边界。
