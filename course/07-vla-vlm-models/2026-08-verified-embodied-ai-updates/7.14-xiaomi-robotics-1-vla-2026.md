# Xiaomi-Robotics-1：10 万小时真实轨迹驱动的 VLA 基础模型

> 作者：Damon Li | 更新日期：2026年8月22日
> 证据状态：预印本（arXiv），代码与模型 checkpoint 承诺开源

## 1. 结论与证据等级

Xiaomi-Robotics-1 是小米机器人团队于 2026 年 7 月发布的视觉-语言-动作（VLA）基础模型，其核心贡献在于以超过 10 万小时 UMI 设备采集的真实操作轨迹进行大规模预训练，并通过自动语言标注管线为轨迹片段生成描述场景状态转移的自然语言条件，再经后训练阶段对齐到机器人本体与人类指令。[1]

该工作在 RoboCasa365 上达到 57.4% 成功率（此前最优 46.6%），在 RoboDojo 上平均得分 20.07（此前最优 13.07），展示了明确的预训练 scaling behavior。[1]

## 2. 问题设定、符号与假设

### 2.1 符号表

| 符号 | 含义 |
| :--- | :--- |
| $o_t$ | 第 $t$ 步观测（RGB 图像 + 本体感觉） |
| $\ell$ | 语言指令（自动标注或人类自然语言） |
| $a_t$ | 动作（末端执行器位姿增量或关节角） |
| $e$ | 机器人本体（embodiment） |
| $\pi_\theta(a_t \mid o_{\le t}, \ell, e)$ | VLA 策略 |
| $\mathcal{D}_{\mathrm{UMI}}$ | UMI 设备采集的 100K+ 小时轨迹数据集 |
| $\mathcal{D}_{\mathrm{robot}}$ | 后训练阶段的跨本体机器人数据 |
| $\theta_{\mathrm{pre}}, \theta_{\mathrm{post}}$ | 预训练与后训练参数 |

### 2.2 学习问题

Xiaomi-Robotics-1 将 VLA 训练分解为两个阶段：

1. **预训练**：在 $\mathcal{D}_{\mathrm{UMI}}$ 上学习通用的动作生成能力。此阶段使用 UMI 手持设备采集的人类操作视频，不依赖特定机器人本体；自动标注管线为轨迹片段生成描述状态转移的自然语言。
2. **后训练**：在 $\mathcal{D}_{\mathrm{robot}}$ 上对齐到具体机器人本体和人类指令格式，使策略能在未见环境中执行移动操作任务。

**关键假设**：
- UMI 设备采集的人类操作轨迹与机器人操作存在足够的运动学相似性，使得预训练阶段习得的"场景状态转移 → 动作"映射能迁移到机器人本体。
- 自动语言标注的质量足以提供有效的条件信号。
- 预训练 scaling behavior 能迁移到后训练阶段的真实机器人性能。

## 3. 方法与完整推导

### 3.1 架构

Xiaomi-Robotics-1 采用 VLM backbone（Qwen3-VL）与 Diffusion-Transformer（DiT）action head 的组合，并通过 Mixture-of-Transformers（MoT）架构降低推理延迟。[1]

策略的条件分布可写为：

$$
\pi_\theta(a_t \mid o_{\le t}, \ell, e) = \int p_\phi(a_t \mid z_t, \ell, e) \, p_\psi(z_t \mid o_{\le t}, \ell) \, dz_t
$$

其中 $z_t$ 是 VLM backbone 提取的视觉-语言融合表征，$p_\phi$ 是 DiT action head 参数化的扩散策略，$p_\psi$ 是 VLM 的视觉-语言编码器。

### 3.2 预训练目标

预训练阶段在 $\mathcal{D}_{\mathrm{UMI}}$ 上优化动作生成的条件似然。对于扩散 action head，其训练目标等价于去噪得分匹配：

$$
\mathcal{L}_{\mathrm{pre}}(\theta) = \mathbb{E}_{(o, \ell, a) \sim \mathcal{D}_{\mathrm{UMI}},\, t \sim \mathcal{U}(0,1),\, \epsilon \sim \mathcal{N}(0,I)}
\left[ \left\| a - \hat{a}_\theta(a_t^{(t)}, o, \ell, t) \right\|_2^2 \right]
$$

其中 $a_t^{(t)}$ 是对动作 $a$ 施加扩散噪声后的中间状态，$\hat{a}_\theta$ 是模型预测的去噪动作，$t$ 是扩散时间步。

### 3.3 自动语言标注管线

论文提出可扩展的自动标注管线，为轨迹片段生成描述场景状态转移的自然语言。该管线可概括为：

$$
\ell_i = \mathrm{AutoLabel}(\mathrm{clip}_i), \quad \mathrm{clip}_i \subset \tau, \quad \tau \in \mathcal{D}_{\mathrm{UMI}}
$$

其中 $\mathrm{AutoLabel}$ 将轨迹 $\tau$ 切分为片段 $\mathrm{clip}_i$，并基于视觉-语言模型生成描述状态转移的文本。这些标注为预训练提供精确的条件信号，减少对人工标注的依赖。

### 3.4 后训练对齐

后训练阶段在 $\mathcal{D}_{\mathrm{robot}}$ 上微调，目标可写为：

$$
\mathcal{L}_{\mathrm{post}}(\theta) = \mathcal{L}_{\mathrm{pre}}(\theta) + \lambda \mathcal{L}_{\mathrm{align}}(\theta)
$$

其中 $\mathcal{L}_{\mathrm{align}}$ 对齐到具体机器人本体和人类指令格式。论文强调后训练阶段的性能与预训练模型的强度正相关，即更强的预训练模型产生更好的真实机器人性能。

## 4. 训练和推理算法

### 4.1 训练流程

| 阶段 | 输入 | 输出 | 关键组件 |
| :--- | :--- | :--- | :--- |
| 预训练 | UMI 轨迹 + 自动语言标注 | 通用动作生成模型 | Qwen3-VL + DiT + MoT |
| 后训练 | 跨本体机器人数据 + 人类指令 | 对齐后的 VLA 策略 | 本体适配 + 指令对齐 |

### 4.2 推理流程

1. 输入：当前观测 $o_t$、语言指令 $\ell$、机器人本体信息 $e$。
2. VLM backbone 编码视觉-语言表征 $z_t$。
3. DiT action head 通过扩散采样生成动作块 $\hat{a}_{t:t+H}$（$H$ 为动作块长度）。
4. 执行动作块并按控制频率刷新。

## 6. 失败模式、局限性与复现条件

1. **UMI → 机器人迁移假设**：预训练依赖 UMI 人类操作与机器人操作之间的运动学相似性。对于接触丰富、需要精确力控的任务，这一假设可能不成立。
2. **自动标注质量**：自动语言标注的准确性直接影响预训练条件信号质量。论文未提供标注质量的定量评估。
3. **仿真 vs 真实差距**：核心基准结果在仿真中取得；真实机器人展示以视频为主，缺乏统计级真机评测。
4. **基线可比性**：论文未完整说明基线是否使用相同预训练数据规模和计算预算，直接成功率对比可能不完全公平。
5. **开源状态待确认**：论文称"Code and model checkpoints will be released"，但截至本次核验，尚未在 arXiv 页面或项目页确认到可下载的 GitHub 仓库或 HuggingFace 模型。
