# GlanceWAM：以稀疏异步测试时想象兼顾世界模型前瞻与控制时延

> 作者：Damon Li | 更新日期：2026年8月27日
> 证据状态：**预印本 + 官方代码/资源包**。GlanceWAM 于 2026 年 8 月 25 日发布 arXiv v1；同名官方仓库以 MIT 许可公开代码，Hugging Face 资源页托管数据与 checkpoint bundle。[1] [2] [3]

## 1. 结论与证据等级

GlanceWAM 的新意是将生成式视觉前瞻与动作控制放在**不同时间尺度**：视频 DiT 在慢速后台时钟预测大约 3 秒后的单个 lookahead latent，而动作头在前台以 0.8 秒 action chunk 和 48 ms/chunk 的报告速度解码，不等待视觉采样完成。[1] 这不是“取消测试时想象”，而是在不把像素解码放进控制关键路径的前提下保留潜空间的未来条件。

作者在演示数据训练条件下报告：RoboCasa kitchen 24 任务为 72.2%，LIBERO 为 99.0%，并与其设置下的同步 Cosmos Policy（67.1%）及没有想象的 co-training（64.4%）比较；48 ms/chunk 在 NVIDIA A100 上测得。上述指标仅限于论文/仓库定义的 simulator、checkpoint、episode 协议与硬件，不可外推为真实机器人控制承诺。[1] [2]

| 主张 | 证据等级 | 说明 |
|---|---|---|
| 双时钟、潜空间异步 lookahead 与 attention mask | A | 论文原文给出系统和损失定义。[1] |
| 代码、评测脚本与模型/数据 bundle | A | 官方 GitHub 与 Hugging Face 页面可核验。[2] [3] |

## 2. 问题设定、符号与假设

给定演示轨迹中的观测历史 $\mathbf o_{\leq t}$、语言条件 $\mathbf c$ 与连续动作块 $\mathbf a_t\in\mathbb R^{H_a\times D_a}$，目标是同时学习一个未来视觉潜变量与动作策略。论文取 $H_a=16$ step、20 Hz，即 0.8 秒动作时域；前瞻时域为 $H_f\approx3$ 秒。[1]

令 $\mathbf z$ 为视频 VAE latent，$\hat{\mathbf z}_{\mathrm{la}}$ 为生成的 lookahead latent，$\Delta$ 为当前块相对于该 lookahead 的剩余偏移。关键假设是：单个距离较远的视觉目标可为连续若干动作块提供有用空间指引，且策略可在 $\Delta$ 从 $H_f$ 逐渐衰减至 0 时保持可用；异步生成不会因 stale lookahead 使系统失稳。[1]

## 3. 方法与完整推导

训练 window 同时包含三种视觉角色：干净观测 $\mathbf o_{\leq t}$、全时域的加噪未来目标 $\mathbf x_{t+H_f}^{(\tau)}$ 与随机中间偏移 $u\sim\mathcal U(0,H_f]$ 的干净 lookahead $\mathbf x_{t+u}$。为避免未来泄漏，作者对“观测 + 生成目标”和“观测 + lookahead”分两次 VAE 编码，再使用三类 Prefix-LM mask：观测只能看观测；未来生成不能看 lookahead；lookahead 只看观测与自身。[1]

视频 DiT 的条件流匹配目标为：

$$
\mathcal L_{\mathrm{video}}
=\mathbb E_{\tau,\boldsymbol\epsilon,\mathbf z}
\left\|\mathbf v_\theta\!\left(
\mathbf z_{t+H_f}^{(\tau)},\tau\mid\mathbf z_{\leq t},\mathbf c
\right)-(\boldsymbol\epsilon-\mathbf z_{t+H_f})\right\|^2 .
$$

动作头同样学习流场，但条件来自观察与 lookahead 的多层 DiT 表征：

$$
\mathcal L_{\mathrm{action}}
=\mathbb E_{\sigma,\boldsymbol\epsilon_a,\mathbf a}
\left\|\mathbf u_\phi\!\left(
\mathbf a_t^{(\sigma)},\sigma\mid
[\mathbf h_{\mathrm{obs}};\mathbf h_{\mathrm{la}}],\mathbf c,\Delta
\right)-(\boldsymbol\epsilon_a-\mathbf a_t)\right\|^2,
\quad
\mathcal L=\mathcal L_{\mathrm{video}}+\mathcal L_{\mathrm{action}}.
$$

这是论文公开损失的整理。$u$ 的随机化与 $\Delta$ 的显式时间嵌入把“前瞻变旧”纳入训练分布；lookahead token dropout（论文报告概率 0.1）使动作头在前瞻缺失/退化时仍见过无条件情形。[1]

## 4. 训练和推理算法

```text
训练：
1. 采样 (o≤t, c, a_t) 与 u∈(0,H_f]；准备未来噪声目标和中间 lookahead。
2. 两次 VAE 编码，并以 3-class Prefix-LM mask 隔离信息流。
3. 以 L_video 训练未来 latent 流场，以 L_action 训练动作流场；输入 Δ=u。
4. 随机 drop lookahead token，更新共享 DiT 与动作头。

推理：
1. 每约 H_f 秒在后台从当前观察生成一个 lookahead latent。
2. 保持 latent 不解码为 RGB；在前台持续读出 0.8 秒动作块。
3. 将随时钟衰减的 Δ 输入动作头；当新 latent 就绪时替换旧条件。
```

官方仓库说明其动作头沿用 GR00T-style flow matching，骨干为 SkyReels-V2 DF，并将观测和 lookahead 的表征从四个 DiT 层聚合。[1] [2] 后台线程、专用生成 GPU 与控制部署的调度实现会影响端到端时延，不能只以动作头的 48 ms 代表整个机器人闭环。

## 5. 实验设计、基线与结果

| 维度 | 作者报告的协议 | 结果与可比性 |
|---|---|---|
| RoboCasa kitchen | 24 任务、demonstrations only；官方仓库的 checkpoint 表称 50 episodes/task | GlanceWAM 0.721；同步 Cosmos Policy 0.671；无想象 co-training 0.644。仅同环境/数据/实现可比。[1] [2] |
| LIBERO 4-in-1 | 官方仓库提供该 checkpoint 与 sweep 脚本；评测条目为 4 suites × 500 episodes | 0.989；与不同 action space 或模型版本不可直接比。[2] |
| 时延 | 单张 NVIDIA A100，动作 chunk 解码 | 论文报告 48 ms/chunk、相对同步基线 24×；视频生成被异步摊销，不应误读为所有服务成本。 [1] |
| 消融/诊断 | lookahead、attention mask、staleness training、多层特征 | 论文报告 lookahead 对 RoboCasa 有 +8.4% 的贡献；统计不确定性必须保留环境与随机性信息。[1] |

GitHub README 提醒 kitchen 的 run-to-run spread 约为 0.02，且 policy 未设 seed；因此很小的差异不应被解读为可靠排序。[2]

## 6. 失败模式、局限性与复现条件

异步设计的主要风险是 lookahead 老化：动作执行接近生成目标时，视觉条件的剩余时域 $\Delta$ 下降；若环境发生未预测接触、遮挡、对象滑移或语言目标改变，陈旧 latent 可能误导动作。论文以偏移随机化、时间条件和 token dropout 缓解，但不等于已证明开放世界安全性。[1]

性能比较也有边界。RoboCasa 与 LIBERO 是模拟 benchmark；演示训练、任务定义、episode 数、GPU 和数据预处理会共同影响数值。论文的“同期同步基线”是其实现内的对照，不能直接推断所有 WAM/VLA 的实机效果。资源层面，官方 bundle 约 21 GB；完整训练参考 4×H200，而评估还需要不同 Python 版本的 simulator sibling environment，这提高了端到端复现复杂度。[2] [3]
