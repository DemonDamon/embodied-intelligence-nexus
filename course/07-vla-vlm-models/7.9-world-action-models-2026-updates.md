# 7.9 2026年最新进展：从VLA到World Action Models (WAMs)

## 1. 概述
随着具身智能技术的快速演进，2026年上半年见证了从传统的反应式视觉-语言-动作（Vision-Language-Action, VLA）模型向**世界动作模型（World Action Models, WAMs）**的重大范式转变 [1]。传统的VLA模型（如RT-2、Octo）主要通过学习 $p(a|o,l)$ 的映射关系来实现从观察到动作的直接输出，虽然在语义泛化上取得了成功，但缺乏对物理世界未来演变的显式理解。

WAMs通过将**预测性世界建模（Predictive World Modeling）**与**动作生成（Action Generation）**统一在一个具身基础模型中，解决了这一痛点。WAMs不仅预测机器人应该做什么，还预测执行该动作后世界会变成什么样，即优化目标转变为 $p(o',a|o,l)$。这种能力的结合使得机器人能够在执行动作前“想象”结果，从而在复杂、长视野的任务中表现出更高的可靠性和泛化能力。

## 2. 核心原理与架构分类
根据复旦大学等机构在2026年5月发布的系统性综述 [1]，WAMs的架构设计主要分为两大类：级联式（Cascaded）和联合式（Joint）。

### 2.1 级联式 WAM (Cascaded WAM)
级联式架构遵循“未来规划 -> 动作”的逻辑流程。首先，一个世界模型（World Model）合成预期的未来状态，然后一个独立的动作模型（Action Model）从该计划中解码出可执行的控制指令。
- **显式规划**：使用像素级载体，如视频、光流、深度图、法线或4D结构来表示未来状态。
- **隐式规划**：使用潜在特征（Latent features）、未来Token、掩码和隐藏状态条件来指导动作生成。
这种设计的优势在于模块化清晰，但两个阶段之间的耦合质量成为了系统的核心瓶颈。

### 2.2 联合式 WAM (Joint WAM)
联合式架构将未来状态和动作的预测整合在一个共享的模型中，并在联合监督下进行训练。
- **自回归生成**：通过共享的Token空间、多头路由（Multi-head routing）和统一的词表来实现。
- **基于扩散的生成**：采用单引擎或多引擎扩散（Diffusion）以及非自回归生成技术。
联合式WAM通过更紧密的耦合，减少了级联架构中的信息损失和延迟。

## 3. 2026年关键模型与方法

### 3.1 NVIDIA Cosmos 3: 开放的物理AI全能模型
2026年5月底，NVIDIA在GTC Taipei上发布了Cosmos 3，这是首个完全开放的物理AI全能模型（Physical-AI Omnimodel）[2]。Cosmos 3采用双塔混合Transformer（Two-tower Mixture-of-Transformers）设计，将场景理解、世界生成、未来帧预测和机器人关节轨迹输出融合在一次前向传播中。这种“管道折叠（Pipeline collapse）”彻底消除了传统系统中感知、世界模型和策略模型之间的集成税和延迟。

### 3.2 ForceVLA2: 引入触觉与力觉的混合控制
在CVPR 2026上发表的ForceVLA2是首个端到端的、具备力觉感知的混合力-位置控制VLA框架 [3]。受人类感觉运动系统启发，它结合了长程力觉Prompt与短程反射回路，赋予了机器人真正的“手感”。在接触丰富的操作任务中，ForceVLA2的成功率和可靠性大幅提升，超越了早期的pi0和pi0.5模型达48%。

### 3.3 Physical Intelligence π0.5 与 Spirit AI v1.5
Physical Intelligence在2026年推出了π0.5模型，专注于解决开放世界泛化这一机器人领域的巨大挑战 [4]。然而，中国初创公司Spirit AI发布的v1.5模型在RoboChallenge排行榜上以66.09的总分和50.33%的任务成功率超越了π0.5，展示了中国在具身智能算法领域的强劲竞争力 [5]。

### 3.4 Google DeepMind Gemini Robotics
Google在I/O 2026上展示了基于Gemini 2.0构建的Gemini Robotics系列 [6]。该系列增加了3D空间感知能力，并能够实时生成机器人代码。其On-Device版本将强大的基础模型能力直接部署到本地机器人设备上，极大地降低了对云端计算的依赖。

## 4. 总结
2026年标志着具身智能从单纯的“看图说话做动作”（VLA）向“理解世界规律并行动”（WAM）的深刻转变。随着NVIDIA Cosmos 3等开源全能模型的发布，以及力觉感知（ForceVLA2）的引入，机器人的操作能力正变得更加精细和可靠。
