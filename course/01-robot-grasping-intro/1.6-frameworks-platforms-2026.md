# 1.6 2026年具身智能开源框架与平台生态

## 1. 概述
2026年被工业界普遍定义为具身智能的“部署元年（Year of Deployment）” [1]。这一年，具身智能技术从实验室的单点突破，全面转向系统级的开源框架和标准化硬件平台。开源生态的繁荣极大地降低了机器人学习的门槛，加速了从仿真到现实（Sim-to-Real）的转化过程。

本节将重点介绍2026年上半年最具影响力的几个具身智能框架与平台，包括Hugging Face的LeRobot、NVIDIA的Isaac GR00T以及AGIBOT的开源数据集与挑战赛。

## 2. Hugging Face LeRobot Humanoid
2026年5月，Hugging Face发布了LeRobot Humanoid，这是一个专为机器人学习设计的开源、低成本、3D打印人形机器人项目 [2]。

### 2.1 核心特点
- **极低成本**：当前的双足平台硬件成本仅约2,500美元，使用3D打印部件、现成商用组件和廉价电子设备构建。
- **全栈开源**：与仅开源模型或控制器的项目不同，LeRobot Humanoid提供了完整的技术栈，包括硬件BOM、组装文档、运行时环境、系统辨识工具和训练环境。
- **快速迭代**：设计理念强调可重复性和易修改性。当结构件损坏时可以随时重新打印，鼓励研究人员“构建、修改、破坏、修复、仿真、训练和控制”。

### 2.2 工作流闭环
LeRobot Humanoid打通了机器人设计的完整闭环：
1. **设计探索**：在提交硬件制造前，使用简化的机器人表示在控制基准上评估设计选择。
2. **仿真与训练**：在 `lerobot-legged-zoo`（基于MJLab）中训练运动策略。
3. **数据收集与辨识**：使用真实机器人收集数据，通过 `lerobot-humanoid-identification` 工具回放数据集，拟合仿真器参数，缩小Sim-to-Real差距。
4. **真实世界控制**：通过统一的运行时栈（Runtime stack）将策略部署到物理硬件上。

## 3. NVIDIA Isaac GR00T 与 Agent Skills
NVIDIA在2026年全面升级了其物理AI（Physical AI）生态系统，将机器人开发转化为基于Agent的工作流 [3]。

### 3.1 Isaac GR00T 参考人形机器人
在GTC Taipei 2026上，NVIDIA发布了Isaac GR00T Reference Humanoid Robot，这是首个专为学术研究打造的开放人形机器人参考设计 [4]。
- **硬件构成**：结合了Unitree H2 Plus人形底盘（重150磅，31个自由度）和Sharpa Wave触觉五指手。
- **计算核心**：基于NVIDIA Jetson Thor平台。
- **软件支持**：配套发布了 `GR00T-WholeBodyControl` 开源代码库，作为开发和部署高级人形控制器的统一平台。

### 3.2 Agent Skills for Physical AI
NVIDIA在CVPR 2026上展示了由Cosmos 3驱动的Physical AI Agent Skills [5]。这些技能允许研究人员通过AI Agent自动化最常见的开发步骤，包括场景准备、仿真构建、数据生成和策略训练。这极大地加速了机器人的开发周期，将原本需要数天的环境搭建时间缩短至数小时。

## 4. AGIBOT WORLD 2026 与真实世界数据集
中国具身智能领军企业AGIBOT在2026年推动了具身智能向实际部署的转变。

### 4.1 AGIBOT WORLD 2026 数据集
AGIBOT在Hugging Face上开源了AGIBOT WORLD 2026数据集 [6]。该数据集的显著特点是**100%在真实世界环境中收集**，涵盖商业空间、家庭和其他通用场景。
- **Theme 1**：专注于从真实机器人操作中收集的模仿学习数据。
- **Theme 2**：专注于“丰富交互（Rich Interaction）”，推动机器人理解复杂的物理接触。

### 4.2 AGIBOT WORLD CHALLENGE
与ICRA 2026（维也纳）同期举办的AGIBOT WORLD CHALLENGE吸引了来自27个国家的526支团队 [7]。比赛的核心赛道“Reasoning to Action (R2A)”标志着具身AI评估的一个关键转变：从纯仿真分数转向在真实机器人上进行闭环测试和真实任务执行。

## 5. 总结
2026年的框架与平台生态呈现出“软硬解耦、全栈开源、虚实融合”的趋势。LeRobot拉低了硬件门槛，NVIDIA GR00T提供了高性能的标准化参考，而AGIBOT等企业则通过真实世界数据集和挑战赛推动了算法的落地。这些基础设施的完善，为下一代具身智能算法（如WAMs）的爆发奠定了坚实的基础。
