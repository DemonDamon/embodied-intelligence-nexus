# 2026年8月具身动作数据集更新：MotionDecode

> 作者：Damon Li
> 更新日期：2026年8月22日

本子目录归档 ChingMu MotionDecode 具身动作数据集。其核心价值在于提供带有全身动作、手指动作、物体 6DoF 位姿、多视角视频和机器人重定向信息的高精度数据，用于人形机器人模仿学习、动作生成、视觉—动作联合建模和仿真训练。

## 使用原则

1. 数据集主页中的路线图（例如 2000 小时和 3000 小时扩展）不等同于已经可下载的数据。
2. 下载前应在 Hugging Face 数据集卡中确认具体文件、许可证、访问限制与版本号。
3. 人类动作到机器人动作的重定向仅产生初始参考轨迹；进入真机前仍应在目标机器人模型中进行碰撞、关节限位、动力学和接触稳定性检查。
