# 2026 年 7—8 月具身智能数据集与基准：Open-AoE 与 DexVerse

> 作者：Damon Li | 更新日期：2026年8月22日
> 证据状态：预印本（arXiv）

## 1. 结论与证据等级

Open-AoE 和 DexVerse 分别代表数据集与基准测试在 2026 年 7 月的重要进展。Open-AoE 以消费级手机采集约 2,000 小时第一人称操纵视频，提供从采集到训练的完整工具链；DexVerse 构建涵盖 100 个任务、3 种机器人臂和 6 种灵巧手的模块化灵巧操作基准。[1] [2]

| 资源 | 类型 | 核心价值 | 证据等级 | 开源状态 |
| :--- | :--- | :--- | :--- | :--- |
| Open-AoE | 数据集 + 工具链 | 2,000h 手机采集第一人称操纵视频 + 处理管线 + 下游训练工具 | A | 论文称 open dataset/toolchain |
| DexVerse | 基准测试 | 100 任务 / 3 臂 / 6 手 + VR 遥操作 + 3,180 示范 + 可控视觉变化 | A | 项目页公开 |

## 2. 问题设定、符号与假设

### 2.1 符号表

| 符号 | 含义 |
| :--- | :--- |
| $\mathcal{D}_{\mathrm{AoE}}$ | Open-AoE 数据集 |
| $\tau_i = (v_i, \ell_i, h_i, c_i)$ | 第 $i$ 条轨迹（视频、文本标注、MANO 手姿、相机轨迹） |
| $\mathcal{B}_{\mathrm{DexVerse}}$ | DexVerse 基准 |
| $\mathcal{T} = \{T_1, \ldots, T_{100}\}$ | 100 个灵巧操作任务 |
| $\mathcal{E} = \{e_1^{\mathrm{arm}}, \ldots; e_1^{\mathrm{hand}}, \ldots\}$ | 3 种臂 + 6 种灵巧手 |

### 2.2 Open-AoE 的核心问题

具身智能需要大规模第一人称操纵数据，但专业机器人采集台成本高、场景受限。Open-AoE 探索消费级设备 + 众包采集是否能提供足够的结构化操纵数据。[1]

### 2.3 DexVerse 的核心问题

通用灵巧操作策略需要超越孤立任务的基准，系统评估跨任务、跨感觉条件、跨本体的泛化。现有基准在任务/数据多样性、本体覆盖或可控视觉变化方面受限。[2]

## 3. 方法与完整推导

### 3.1 Open-AoE：采集 → 处理 → 训练全流程

**采集**：500+ 贡献者使用 400+ 智能手机在自然环境中采集。

**处理管线**：

$$
\tau_{\mathrm{raw}} \xrightarrow{\text{时序动作分割}} \{\mathrm{clip}_j\} \xrightarrow{\text{语义标注}} \{(\mathrm{clip}_j, \ell_j)\} \xrightarrow{\text{手部重建}} \{(\mathrm{clip}_j, \ell_j, \mathrm{MANO}_j)\} \xrightarrow{\text{相机轨迹重建}} \tau_{\mathrm{structured}}
$$

每条结构化轨迹包含：
- 文本标注 $\ell_i$
- MANO 手姿参数 $h_i$
- 相机轨迹 $c_i$
- 时空定位的原子动作

**下游工具链**：支持可视化、跨本体 retargeting、模型特定数据转换和 VLA/WAM/World Model 训练 recipe。

### 3.2 DexVerse：模块化基准设计

DexVerse 的 100 个任务覆盖 8 类操作技能：

| 技能类别 | 示例 |
| :--- | :--- |
| 抓取与重定位 | 物体 pick-and-place |
| 铰接物体交互 | 开门、开抽屉 |
| 功能性工具使用 | 使用锤子、螺丝刀 |
| 双手协调 | 双臂搬运 |
| 非抓取控制 | 推、滑 |
| 接触丰富行为 | 插入、拧转 |
| 多目标执行 | 同时满足多个子目标 |
| 长时程多阶段 | 串联多步操作 |

**可控视觉变化**：纹理、背景、光照和相机视角可配置。

**示范数据**：3,180 条 VR 遥操作示范，包含同步的本体感觉、RGB、深度、点云和状态观测。

**评测基线**：Diffusion Policy、DP3、OpenVLA、$\pi_{0.5}$ 在 19 个任务上的基准结果。

## 6. 失败模式、局限性与复现条件

1. **Open-AoE 的手机采集质量**：消费级手机的相机标定、帧率和运动模糊可能不如专业采集设备；众包标注一致性需要额外质量控制。
2. **Open-AoE 的人类→机器人迁移假设**：MANO 手姿到机器人灵巧手的 retargeting 仍存在运动学差距。
3. **DexVerse 的仿真 vs 真实差距**：100 个任务在仿真中定义，仿真物理与真实操作的差距可能影响结论的迁移性。
4. **DexVerse 的基线可比性**：Diffusion Policy、DP3、OpenVLA 和 $\pi_{0.5}$ 使用不同架构和数据效率，直接成功率对比需注明条件差异。
5. **开源状态**：Open-AoE 论文称 open dataset/toolchain，具体下载链接需以 arXiv 页面或项目页为准；DexVerse 项目页公开但代码仓库需确认。
