# 2026 年 7—8 月灵巧操作与遥操作：可重构平台、接触级遥操作与力记忆 VLA

> 作者：Damon Li | 更新日期：2026年8月22日
> 证据状态：预印本（arXiv）

## 1. 结论与证据等级

2026 年 7—8 月灵巧操作研究的核心趋势是从"视觉主导向接触、力、触觉状态建模转变"和"从动作重映射走向接触级意图执行"。Handroid 提出桌面级可重构双本体平台（灵巧手 ↔ 桌面人形）；TeleDexter 实现手-物体协同追踪的接触级遥操作；AnyDexRT 解决跨灵巧手免标定 motion retargeting；MIDAS Hand 提供开源低阻抗直接驱动灵巧手；FM-VLA 为 VLA 引入力记忆。[1] [2] [3] [4] [5]

| 工作 | 核心创新 | 证据等级 | 开源状态 |
| :--- | :--- | :--- | :--- |
| Handroid | 27-DoF 可重构双本体（灵巧手/桌面人形） | A | 项目页公开 |
| TeleDexter | hand-object co-tracking controller + 接触执行策略 | A | 未确认 |
| AnyDexRT | 免标定灵巧手 retargeting + few-shot 人类示教 | A | 未确认 |
| MIDAS Hand | 开源模块化低阻抗直接驱动灵巧手 | A | 设计文件、API、仿真模型开源 |
| FM-VLA | VAE 力历史压缩 → force memory tokens → VLA | A | 项目页公开 |

## 2. 问题设定、符号与假设

### 2.1 符号表

| 符号 | 含义 |
| :--- | :--- |
| $q^{\mathrm{hand}}_t$ | 人手关节状态 |
| $q^{\mathrm{robot}}_t$ | 机器人灵巧手关节状态 |
| $f_t$ | 力/触觉信号序列 |
| $z^{\mathrm{force}}_t$ | 力记忆 token |
| $\mathrm{CoTrack}(h, o)$ | 手-物体协同追踪状态 |
| $\mathrm{Retarget}(q^{\mathrm{hand}}, e)$ | 从人手到机器人灵巧手 $e$ 的运动重映射 |

### 2.2 各工作核心问题

- **Handroid**：灵巧手和人形机器人作为独立本体开发，缺乏统一平台研究跨本体学习。[1]
- **TeleDexter**：现有遥操作只做动作重映射，无法传递手-物体动态接触中的操作意图。[2]
- **AnyDexRT**：跨不同灵巧手遥操作需要大量手动标定，阻碍多机构数据复用。[3]
- **MIDAS Hand**：绳索驱动灵巧手背驱力矩高，不适合柔性和触觉操作实验。[4]
- **FM-VLA**：视觉记忆在视觉模糊任务（如按按钮次数）中失效，力历史可提供时间上下文。[5]

## 3. 方法与完整推导

### 3.1 Handroid：可重构双本体平台

Handroid 使用 27-DoF 机电躯体作为两种本体的共享基础：

$$
e_{\mathrm{hand}} = \mathrm{Reconfigure}(q_{1:20}), \quad e_{\mathrm{humanoid}} = \mathrm{Reconfigure}(q_{1:12}^{\mathrm{leg}} + q_{13:24}^{\mathrm{arm}} + q_{25:27}^{\mathrm{head}})
$$

- 灵巧手模式：20 DoF 组成人形手，匹配人手运动学结构。
- 人形模式：相同关节模块重配置为含头、臂、腿的桌面人形，12-DoF 下肢支持行走和全身运动。

统一控制框架支持遥操作、灵巧抓取、手内操作、人形运动、步态生成和交互式动作创作。

### 3.2 TeleDexter：接触级遥操作

TeleDexter 的核心是 hand-object co-tracking controller：

$$
\mathrm{CoTrack}_t = \mathrm{Tracker}(h_t, o_t), \quad a_t = \pi_{\mathrm{contact}}(\mathrm{CoTrack}_t, s_t)
$$

其中 $h_t$ 是操作者手部状态，$o_t$ 是物体状态，$\mathrm{CoTrack}_t$ 是协同追踪状态（手-物体相对关系），$\pi_{\mathrm{contact}}$ 是学习到的低层接触执行策略。系统通过连续 co-tracking subgoal 提升手内旋转、重定位和精细操作。

### 3.3 AnyDexRT：免标定 retargeting

AnyDexRT 结合自监督指尖对应关系学习、few-shot 人类示教和接触分类器：

$$
\hat{q}^{\mathrm{robot}} = \mathrm{Retarget}(q^{\mathrm{hand}}; \mathcal{C}_{\mathrm{self-sup}}, \mathcal{D}_{\mathrm{few-shot}}, \mathrm{Classifier}_{\mathrm{contact}})
$$

其中 $\mathcal{C}_{\mathrm{self-sup}}$ 是自监督学习的指尖对应关系，$\mathcal{D}_{\mathrm{few-shot}}$ 是少量人类示教，$\mathrm{Classifier}_{\mathrm{contact}}$ 优化 pinch 相关姿势。

### 3.4 MIDAS Hand：低阻抗直接驱动

MIDAS Hand 采用直接驱动关节和刚性连杆（非绳索驱动），降低背驱力矩：

| 参数 | 值 |
| :--- | :--- |
| 总自由度 | 16 |
| 主动自由度 | 13 |
| 触觉传感器 | 3-axis taxels，283 个 tactile elements |
| 组装时间 | ~3 小时（3D 打印模块化） |
| 驱动方式 | 直接驱动（低摩擦传动） |

### 3.5 FM-VLA：力记忆 VLA

FM-VLA 用 VAE 预训练力时间序列重建，将力历史压缩为 force memory tokens：

$$
z^{\mathrm{force}}_t = \mathrm{VAE}_{\mathrm{enc}}(f_{t-K:t}), \quad \hat{f}_{t-K:t} = \mathrm{VAE}_{\mathrm{dec}}(z^{\mathrm{force}}_t)
$$

VAE 训练目标：

$$
\mathcal{L}_{\mathrm{VAE}} = \mathbb{E}_{q} \left[ \| f - \hat{f} \|_2^2 \right] + D_{\mathrm{KL}}(q(z \mid f) \| p(z))
$$

将 $z^{\mathrm{force}}_t$ 和短状态历史作为额外条件 token 投影到 action expert：

$$
a_t = \pi_\theta(a_t \mid o_t, \ell, z^{\mathrm{force}}_t, s_{t-k:t})
$$

## 6. 失败模式、局限性与复现条件

1. **Handroid 的桌面尺度限制**：0.33m 高度和 2.05kg 重量适合桌面实验，但不代表全尺寸人形的动力学约束。
2. **TeleDexter 的接触感知依赖**：co-tracking controller 依赖手-物体状态的实时感知，遮挡和感知噪声可能影响追踪质量。
3. **AnyDexRT 的 few-shot 依赖**：仍需要少量人类示教，完全 zero-shot 跨灵巧手迁移未实现。
4. **MIDAS Hand 的驱动方式限制**：直接驱动可能在高力输出场景中不如绳索驱动紧凑。
5. **FM-VLA 的力传感器依赖**：需要机器人配备力/触觉传感器；传感器噪声和漂移影响力记忆质量。VAE 重建质量决定了力记忆的信息保留程度。
6. **共同局限**：Handroid、TeleDexter、AnyDexRT 的代码/设计文件开源状态需进一步确认。
