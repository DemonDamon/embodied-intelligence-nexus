# 2026 年 8 月：密集视觉表征与操作策略专题

> 作者：Damon Li
> 更新日期：2026年8月23日

本专题连接“深度学习抓取”与“视觉表征学习”：抓取/插入失败往往不只来自动作头，也来自视觉特征在进入策略前被过度池化。归档文档重点核验 dense patch、冻结视觉骨干、block-causal 时序融合以及真机接触操作的实验设计。

## 使用提示

Patch Policy 的官方代码公开了四个仿真环境和数据集，但没有公开完整真机演示数据。复现时应首先从仿真启动，记录 encoder、观察窗口、动作头与单 GPU/多 GPU 配置；对真机迁移则需单独完成相机标定、延迟测量、安全停止和接触失败分析。
